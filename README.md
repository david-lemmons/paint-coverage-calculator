# Paint Coverage Calculator

A Python terminal program designed to assist in calculation of wall area and how many gallons of paint needed for 1 coat of paint.

## Features

- Calculates Wall area
- Calculates gallons of paint needed per coat
- Checks user input

## How to Run

Requires Python 3

run `python main.py` from the project folder

## Assumptions

- Measurements are in feet
- Coverage is entered by the user in square feet per gallon per coat.
